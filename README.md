# Courier Management System

A full-stack web-based Courier Management System developed to manage and monitor courier operations through a centralized application.

The system provides modules for shipment tracking, branch operations, bags, manifests, vehicles, employees, customers, documents, payments, and delivery management.

## Features

- User Login and Registration
- Dashboard with courier statistics
- Branch Inscan Management
- Document Management
- Bag Management
- Vehicle Management
- Manifest Management
- Shipment Tracking
- Delivery Management
- Customer Management
- Payment Management
- Employee Management
- RESTful API integration
- MySQL database integration
